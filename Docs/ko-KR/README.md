# **VRC Scaler OSC 설명서**

## **일. 소개**

VRC Scaler OSC는 VRChat에서 아바타 신장을 변경하기 위한 도구 응용 프로그램입니다. VRChat에 OSC 패킷을 전송하여 플러그인(기믹)을 설치하지 않고도 아바타를 작동시킬 수 있으며, 이론적으로 모든 아바타의 신장을 수정할 수 있습니다.

### **1.1 주요 특징**

* 허용 범위 내에서 아바타 신장을 임의로 수정할 수 있으며, 즉시 변경 또는 부드러운 전환을 선택할 수 있습니다. 신장 값의 단위는 미터, 배수, 증감 백분율 등 다양한 방식으로 입력할 수 있으며, 피트 및 인치 입력은 자동으로 미터로 변환됩니다.
* 제스처 신장 조정 기능을 지원합니다. "세계 확대/축소" 클래식 모드, 다양한 제스처 조합 선택 또는 비활성화가 가능합니다.
* 중국어, 영어, 일본어, 한국어 인터페이스를 사용할 수 있으며, Windows 64비트 및 Linux 64비트 버전이 있습니다.
* 특정 이름의 아바타 매개변수를 통해 제어할 수 있으며, 아바타 메뉴 제어 플러그인 개발 가능성이 있습니다.

### **1.2 프로그램 버전**

* 프로그램은 C#으로 작성되었으며, 자체 개발한 OSC 패킷 처리 패키지 및 [VRC OSC Query](https://github.com/vrchat-community/vrc-oscquery-lib)를 사용합니다
* 데스크톱 (Windows) 버전: 중국어, 영어, 일본어, 한국어 인터페이스, Windows 10 이상 OS 지원
* 명령줄 (Console) 버전: 영어 인터페이스, Windows 및 Linux 64비트 OS 지원
* MIT 라이선스 하에서 오픈소스화할 예정입니다. 시스템이 지원하지 않는 경우 소스 코드에서 직접 컴파일하거나 수정할 수 있습니다.

### **1.3 빠른 시작 가이드**

PC 모드:
1. VRCScalerOSC_Windows.exe를 실행합니다.
2. 창 하단의 현재 신장 뒤에 현재 아바타 신장 값이 표시되는지 확인합니다.
3. 조정할 캐릭터 신장을 선택하거나 입력합니다.
4. [스케일링 실행] 버튼을 클릭합니다.

![](image/img1.3.1.png)
![](image/img1.3.2.png)

VR 모드:
1. VRCScalerOSC_Windows.exe를 실행합니다.
2. VRChat에서 [OSC] 및 [OSC를 통한 머리와 손목 트래킹 데이터 전송]을 활성화합니다.
3. 양손 컨트롤러의 그립 버튼을 누른 상태에서 Mute 버튼을 두 번 눌러 그립 제스처 스케일 기능을 활성화합니다.
4. 양손으로 그립 버튼을 계속 누른 상태에서 손을 멀리하면 키가 커지고, 손을 가까이하면 키가 작아집니다.

### **1.4 자주 묻는 질문**

* 신장을 변경할 수 없는 이유는 무엇입니까?  
  A: 먼저 VRChat에서 OSC 기능이 활성화되어 있는지 확인하세요.

* 응용 프로그램 화면의 아바타 신장 정보가 업데이트되지 않는 이유는 무엇입니까?  
  A: 수신 포트가 이미 사용 중이거나 방화벽/안티바이러스 소프트웨어가 네트워크 기능을 차단하고 있는지 확인하세요. VRChat 스탠드얼론 버전(Quest, Pico)을 사용하는 경우, VRC Scaler OSC는 현재 이러한 버전에서 OSC 패킷을 수신할 수 없으며 전송만 가능합니다. 따라서 현재 상태 표시, 제스처 스케일링 및 VRChat 메뉴를 통한 VRC Scaler OSC 제어 기능이 정상 작동하지 않습니다.

* VRC Scaler OSC는 다른 OSC 도구와 충돌합니까?  
  A: VRC Scaler OSC는 VRC OSC Query와 무작위 수신 포트 기능을 사용하여 포트 충돌을 피합니다. VRC OSC Query가 정상 작동하지 않으면 [VOR](https://github.com/SutekhVRC/VOR)과 같은 OSC 패킷 배포 전달 도구를 사용하여 충돌을 처리할 수 있지만, VRC OSC Query에 의존하는 제스처 스케일링 기능이 정상 작동하지 않을 수 있습니다.

* 제스처 스케일링 기능이 정상 작동하지 않는 이유는 무엇입니까?  
  A: 먼저 화면의 아바타 신장 정보가 신장 변화에 따라 업데이트되는지 확인하세요. 정상 업데이트되지만 제스처 스케일링이 작동하지 않는다면, 설정 화면에서 [OSC를 통한 머리와 손목 트래킹 데이터 전송]이 활성화되지 않았거나 VRC OSC Query가 정상 작동하지 않을 수 있습니다.

* VRC Scaler OSC를 설치하거나 사용할 때 문제가 발생하면 어떻게 해야 합니까?  
  A: VRC Scaler OSC가 배포된 웹사이트 또는 Discord 채널에서 작가의 지원을 요청하세요.

### **1.5 관련 제품**

* Real Size Scale Adjuster (RSSAdj) v2: VRC Scaler OSC를 기반으로 하는 아바타 플러그인입니다. 플레이어가 VRChat의 메뉴를 통해 신장을 조정할 수 있습니다.
* Menu Control Camera (MCC): OSC를 사용하여 VRC 카메라 명령을 전송합니다. 플레이어가 메뉴 옵션을 통해 카메라 설정을 조정하고 사진을 찍을 수 있습니다. 아바타 크기가 너무 커서 카메라를 제어하기 어려운 문제를 해결합니다. Lite 버전은 이미 RSSAdj v2에 통합되어 있습니다.

### **2.1 창 설정**

인터페이스 언어는 컴퓨터의 운영 체제 언어를 자동으로 따릅니다. 시스템이 중국어, 일본어, 한국어가 아닌 경우 영어 버전이 기본값입니다. 수동으로 전환해야 하는 경우 [Lang.] 버튼을 클릭하고 언어를 선택하세요.  

![](image/img2.1.1.png)

데스크톱 해상도가 높고 디스플레이 배율이 100%인 경우 창이 작게 보일 수 있습니다. [크기] 버튼을 클릭하여 크기를 조정할 수 있습니다. 최대 4배(길이와 너비는 2배)까지 확대할 수 있습니다.  

![](image/img2.1.2.png)

[간편 모드]를 클릭하면 원본 창이 고정 신장 값 제어 패널로 교체되어 사용자가 다양한 신장 값의 버튼을 통해 더 직접적으로 신장을 변경할 수 있습니다. 자세한 내용은 섹션 2.8을 참조하세요.

### **2.2 신장 조정**

왼쪽 상단의 [아바타 크기]에 신장을 직접 입력한 후 [스케일 변경]을 눌러 신장을 변경합니다. [▼]를 클릭하면 기본 신장 메뉴가 열리고 신장을 빠르게 선택할 수 있습니다. [배]를 사용하여 스케일링하려면 [m]를 클릭하고 배율로 전환할 수 있습니다. [기본 키 복원]를 클릭하면 아바타 업로드 시의 기본 신장으로 즉시 복원됩니다.

![](image/img2.2.1.png)

[아바타 크기]의 단위는 [미터] 또는 [배]로 선택할 수 있습니다. [배]를 선택하면 입력된 값은 아바타 기본 신장의 배수를 나타냅니다. 현재 신장을 기반으로 계산하려면 백분율 숫자를 입력하고 끝에 % 기호를 추가한 후 [Enter] 키를 누릅니다. 입력된 값은 현재 신장의 백분율을 기반으로 자동으로 변환됩니다. 입력된 값이 + 또는 - 기호로 시작하면 변환 결과가 현재 신장에 추가됩니다.

[아바타 크기] 필드에는 영국식 단위에 익숙한 사용자가 치수를 입력하기 쉽도록 하는 자동 피트 인치 변환 기능도 있습니다. 입력된 값에 " 또는 ' 기호가 포함된 문자열(예: 5'3")이 있으면 영국식 단위 입력으로 간주되며, 입력된 값이 자동으로 해당 미터 값으로 변환되고 단위도 자동으로 [m]로 전환됩니다.

### **2.3 스케일링 범위**

스케일링 범위는 VRC Scaler OSC에 의한 신장 변경의 최대값과 최소값을 제한하는 데 사용됩니다. 이 기능은 VRChat의 기본 제공 캐릭터 스케일링, 월드 스케일링 또는 기타 신장 조정 도구의 스케일링 효과에 영향을 주지 않습니다. 캐릭터 신장 블록의 오른쪽 상단 모서리에 있는 기어 아이콘을 클릭하여 스케일링 범위 설정 메뉴를 엽니다. 다음 옵션이 있습니다:

* Avatar 기본값 (0.2 ~ 5m): VRChat의 기본 제공 스케일링 범위와 동일
* World 기본값 (0.1 ~ 100m): VRChat의 월드에서 과거에 허용된 신장 범위
* 안전 기본값 (0.05 ~ 3000m): VR 플레이어가 손에 들고 있는 원형 메뉴를 볼 수 있는 권장 범위
* VRChat 제한값 (0.01 ~ 10000m): VRChat에서 현재 허용되는 신장 변경의 최대 범위
* 사용자 설정 파일: 사용자 프로필에 설정된 값. 특별히 설정하지 않으면 최대 범위
* 상한을 선택값으로 설정: 입력된 캐릭터 신장을 상한으로 설정합니다. 값은 1미터 이상이어야 합니다
* 하한을 선택값으로 설정: 입력된 캐릭터 신장을 하한으로 설정합니다. 값은 1미터 이하여야 합니다

### **2.4 스케일링 속도 및 시간**

스케일링 속도 또는 시간을 수정하면 다양한 부드러운 스케일링 효과를 얻을 수 있습니다. [정속 스케일]이 선택된 경우, 초당 변경되는 배수는 일정하며, 필요한 스케일링 시간은 대상 신장과 현재 신장의 차이에 따라 증가합니다. [정속 스케일]을 선택 해제하면 고정 스케일링 시간 모드로 전환되며, 스케일링 속도는 대상 신장과 현재 신장의 차이에 따라 증가합니다.

부드러운 스케일링 효과가 필요하지 않고 [스케일 변경]을 누르면 즉시 신장이 변경되도록 하려면 스케일링 속도를 10000으로 설정하거나 스케일링 시간을 0으로 설정합니다.

![](image/img2.4.1.png)
![](image/img2.4.2.png)

[자동 중단]을 선택하면 부드러운 스케일링 중에 현재 신장이 예상 범위 내에 있는지 감지됩니다. VRChat의 기본 제공 신장 조정 기능, 월드 신장 수정 또는 기타 아바타 신장 도구의 사용으로 인해 현재 신장이 예상 범위를 벗어나면 부드러운 스케일링이 자동으로 중단됩니다. VRC Scaler OSC 응용 프로그램이 VRChat에서 OSC 패킷을 수신하지 않으면 현재 신장을 감지할 수 없으므로 [자동 중단] 기능이 정상 작동하지 않을 수 있습니다. 이 경우 [자동 중단]을 선택 해제하여 이 기능을 비활성화하는 것이 좋습니다.

### **2.5 제스처 스케일링**

이 기능은 VR 모드에서 두 손 컨트롤러의 버튼 조합을 사용하고 두 손 컨트롤러가 서로 가까워지거나 멀어지는 동작과 결합하여 아바타 신장을 직접 조정합니다. 기본 제스처 스케일링 모드는 두 손이 가까워지면 점차 축소되고, 두 손이 멀어지면 점차 확대됩니다. [월드 스케일링]를 선택하면 두 손으로 세계의 크기를 제어하는 것과 유사하게 되며, 자신은 상대적으로 크거나 작아집니다.

[월드 스케일링]에서 두 손을 가깝게 하면 세계가 축소되어 자신이 커지고, 두 손을 멀리하면 세계가 확대되어 자신이 작아집니다. 컨트롤러 버튼 조합은 5가지입니다. L은 왼손 컨트롤러, R은 오른손 컨트롤러, T는 트리거 버튼, G는 그립 버튼을 나타냅니다. 예를 들어 [LT+RG]는 왼손 트리거와 오른손 그립을 동시에 눌러 제스처 스케일링을 트리거해야 함을 의미합니다.

![](image/img2.5.1.png)
![](image/img2.5.2.png)

[Mute 더블탭으로 제스처 설정]을 활성화하면 양손 컨트롤러의 스케일 버튼을 누른 상태에서 Mute 키를 두 번 눌러 제스처 스케일에 사용할 버튼 조합을 변경할 수 있습니다. 제스처 스케일을 끄려면 아무 버튼도 누르지 않은 상태에서 음소거 키를 두 번 누르세요.

![](image/img2.5.3.png)

마이크가 [토글] 모드가 아닌 경우 이 기능은 정상적으로 동작하지 않습니다. 이 경우 [귀마개 모드] 스위치를 대신 사용할 수 있습니다. [귀마개 모드]를 사용해 전환하면 약 0.5초의 지연이 발생하므로, 트리거로 [귀마개 모드]를 전환한 후 변경할 제스처 버튼을 누르세요.

![](image/img2.5.4.png)

제스처 스케일링 기능은 VRC 아바타 매개변수의 GestureLeft 및 GestureRight 매개변수에 의존하여 컨트롤러 버튼 상태를 추론하므로, 실제 컨트롤러 버튼 상태와 약간 다를 수 있습니다. 다음 표를 참조하세요:

| 제스처 이름 | 제스처 매개변수 값 | 트리거 버튼 눌림 (T) | 그립 버튼 눌림 (G) |
| :---- | :---- | :---- | :---- |
| Neutral | 0 | ❌ | ❌ |
| Fist | 1 | ✅ | ✅ |
| HandOpen | 2 | ❌ | ❌ |
| FingerPoint | 3 | ❌ | ✅ |
| Victory | 4 | ❌ | ❌ |
| RockNRoll | 5 | ✅ | ❌ |
| HandGun | 6 | ❌ | ✅ |

### **2.6 OSC 설정**

VRC Scaler OSC 응용 프로그램은 VRC OSCQuery를 사용하여 자동 포트 구성 기능을 구현하고 다른 OSC 응용 프로그램과의 충돌을 피합니다. [수신 port 자동 설정]을 선택 해제하면 응용 프로그램은 지정된 포트에서 VRChat에 OSC 패킷을 전송하도록 알립니다. VRChat.exe가 다른 컴퓨터 또는 VR 헤드셋에서 실행 중인 경우 [대상 IP]에 해당 장치의 IP를 입력하세요. VRChat이 OSC 패킷을 수신하는 포트를 수정한 경우 [송신 port]에서 조정하세요. 설정을 수정한 후 [적용]을 다시 클릭하여 변경 사항을 적용해야 합니다. [정지]를 클릭하면 응용 프로그램의 OSC 패킷 송수신 기능이 즉시 중지됩니다.

### **2.8 간편 모드**

이는 간소화된 버전의 제어 화면으로, 화면의 25개 크기 버튼을 클릭하기만 하면 아바타 신장을 변경할 수 있습니다. 기본 부드러운 스케일링 속도는 초당 2배입니다. [인스턴트 스케일링]을 선택하면 부드러운 스케일링이 비활성화됩니다. 버튼의 값 단위는 기본적으로 미터입니다. [m→배수]를 선택하면 단위를 미터에서 아바타 기본 신장을 기반으로 하는 배수로 변환할 수 있습니다. %로 끝나는 버튼의 기능은 현재 신장을 기준으로 고정 백분율을 증가 또는 감소시키는 것입니다. [중지]를 클릭하면 부드러운 스케일링이 즉시 중단됩니다. [기본 키]을 클릭하면 아바타 업로드 시의 기본 신장으로 직접 변경됩니다. [뒤로가기]를 클릭하면 일반 버전의 제어 화면으로 돌아갑니다.

### **2.9 명령줄 (Console) 버전**

명령줄 버전은 데스크톱 버전의 대부분의 기능을 포함합니다. 주요 차이점은 키보드 작동이 필요하고 영어 버전만 있으며 Linux 64비트 OS의 컴파일 버전을 사용할 수 있다는 것입니다. 도움말 페이지를 전환하려면 [z] 키를 사용하고, 나머지 명령어는 입력 후 [Enter] 키를 눌러 실행해야 합니다. [↑][↓] 키를 사용하여 명령어 기록을 탐색할 수 있습니다.

**실시간 표시 정보**:

* **Current height:** VRChat에서 OSC 패킷을 통해 가져온 현재 아바타 신장
* **Default height:** 아바타 업로드 시 기본 신장
* **Scale:** 현재 신장이 기본 신장의 배수로 표현된 값
* **Range:** 현재 스케일링의 상한 및 하한
* **Scaling time:** 부드러운 스케일링 시간 (초 단위)
* **Scaling rate:** 부드러운 스케일링 속도 (배/초 단위)
* **FixedRate:** 정속 스케일링 설정 상태
* **Auto-Abort:** 자동 중단 설정 상태
* **Gesture:** 제스처 스케일링 설정 상태

**일반 모드 스케일링 명령**:

* **exit:** 응용 프로그램 종료
* **c:** 스케일링 중지
* **d:** 기본 신장으로 복원
* **h[숫자][단위]:** 지정된 [숫자]의 신장으로 즉시 스케일링합니다. [단위]는 [m], [x], [p]를 입력할 수 있으며, 각각 미터, 배수, 현재 아바타 신장을 증감하는 백분율을 나타냅니다.
* **s[숫자][단위]:** 지정된 [숫자]의 신장으로 부드럽게 스케일링합니다. [단위] 설명은 위와 동일합니다
* **g[숫자]:** 제스처 스케일링 제어. [숫자]는 0~5를 입력할 수 있으며, 각각: 0: 제스처 스케일링 비활성화, 1: LT+RT, 2: LG+RG, 3: LT+RG, 4: LG+RT, 5: LT+RT+LG+RG
* **ws:** [월드 스케일링 모드] 켜기/끄기 전환
* **dm:** [음소거 버튼을 두 번 클릭하여 스케일링 제스처 전환] 켜기/끄기 전환

![](image/img2.9.1.png)

**컴팩트 모드 스케일링 명령**:

* **q[숫자]:** 지정된 숫자로 표현된 신장 값으로 즉시 스케일링합니다
* **w[숫자]:** 지정된 숫자로 표현된 신장 값으로 부드럽게 스케일링합니다

  지정된 숫자와 신장은 화면에 표시된 값을 참조하세요. 아래 예시에서 숫자 11은 15미터를 나타냅니다.

![](image/img2.9.2.png)

**시스템 구성 명령**:

* **ip[IPv4 주소]:** OSC에 사용할 IP를 구성합니다
* **port s [숫자]:** OSC 전송 패킷 포트를 구성합니다. 기본값은 9000입니다
* **port r [숫자]:** OSC 수신 패킷 포트를 구성합니다. 기본값은 9010~9100 범위의 무작위 값입니다
* **t[숫자]:** 스케일링 시간을 초 단위로 구성하고 정속 스케일링을 비활성화합니다
* **r[숫자]:** 스케일링 속도를 배/초 단위로 구성하고 정속 스케일링을 활성화합니다
* **f:** [정속 스케일링] 켜기/끄기 전환
* **a:** [자동 중단] 켜기/끄기 전환
* **m[숫자]:** 스케일링 신장 최대값을 구성합니다
* **n[숫자]:** 스케일링 신장 최소값을 구성합니다

![](image/img2.9.3.png)

  화면 하단에 계속 "Waiting for initialization"이 표시되면 VRChat의 OSC 패킷을 기다리고 있음을 의미하며, 이 시점에는 올바르게 표시되지 않습니다.

## **3.2 크기 메뉴 동기화 기능**

VRC Scaler OSC의 특징 중 하나는 사용자가 컴팩트 모드의 스케일링 메뉴 값을 사용자 정의할 수 있다는 것입니다. 이전 섹션에서 언급한 /DefaultValue{n} 시리즈 매개변수는 이 기능을 아바타 플러그인의 크기 목록과 동기화하는 구현 방법입니다. 메뉴 동기화 기능 외에도 사용자는 VRChat의 메뉴를 통해 신장 값을 저장하고 나중에 필요할 때 해당 값으로 스케일링할 수 있습니다.

현재 위치 할당은 다음과 같습니다:

| 위치 번호 | 기본값 | 용도 |
| :---- | :---- | :---- |
| 0 | 0 | 임시 신장 기능용으로 예약됨<br>기본값 0은 아바타 기본 신장으로 스케일링 |
| 1 ~ 25 | 0.01 ~ 10000 | 기본 신장 메뉴 (미터 또는 배수) |
| 26 ~ 33 | -0.5 ~ 0.5 | 기본 신장 메뉴 (현재 신장의 백분율) |
| 34 ~ 100 | 0 | 사용자 정의 |

VRC Expressions Menu에 크기 메뉴를 추가하려면 [RadialPuppet]을 사용하고 [Rotation] 매개변수를 /DefaultValue{n}/Value로 설정하여 값이 메뉴 위에 표시되도록 합니다. 다음으로 메뉴의 기능 요구 사항에 따라 [Parameter] 매개변수를 구성합니다. 예를 들어, [Parameter]를 /DefaultValue{n}/Scaling으로 설정하면 이 [RadialPuppet]을 열 때 /DefaultValue{n}/Value의 값을 사용하여 즉시 스케일링되고, OSC가 false 패킷을 반환하면 메뉴가 즉시 닫힙니다.

![](image/img3.2.1.png)

각 크기 메뉴 옵션에 임시 신장 값 기능을 추가하려면 [Toggle] 또는 [Button]을 사용하여 해당 기능 옵션을 만듭니다. [Button]을 사용하여 [저장] 및 [삭제] 두 개의 버튼을 별도로 만들 수 있습니다. [저장] 버튼의 [Parameter]를 /DefaultValue{n}/Copy로 설정합니다. 버튼을 클릭하면 현재 신장이 해당 /DefaultValue{n}/Value에 저장됩니다. [삭제] 버튼의 [Parameter]를 /DefaultValue{n}/Delete로 설정합니다. 버튼을 클릭하면 저장된 값이 기본값으로 복원됩니다.

[Toggle]을 사용하고 [Parameter] 매개변수를 /SetValue로 설정하여 임시 값 저장/삭제 켜기/끄기 스위치를 만들 수 있습니다.

![](image/img3.2.2.png)

특정 신장 값을 크기 메뉴에 직접 저장하려면 /DefaultValue{n}/InputValue에 0보다 큰 값을 설정합니다. 값을 -1로 설정하면 사용자 임시 값이 삭제됩니다. VRC Scaler OSC 응용 프로그램이 설정 값을 수신하면 이 매개변수가 자동으로 0으로 설정됩니다. 이 매개변수가 0이 되었는지 확인하여 설정 명령이 완료되었는지 판단할 수 있습니다.

### **3.3 MCC 매개변수 전달 기능**

Menu Control Camera (MCC)는 VRC Expressions Menu를 통해 VRC 카메라를 제어할 수 있는 아바타 플러그인입니다. 제어 원리는 아바타 매개변수를 OSC 응용 프로그램으로 전송하고 VRChat에 usercamera 패킷을 반환하여 VRC 메뉴도 카메라 제어 기능을 갖추게 되고, 아바타 신장이 높아서 카메라 패널의 옵션을 클릭하기 어려운 문제를 피합니다. 데스크톱 모드는 이 문제가 없으며 마우스로 카메라 패널의 옵션을 직접 클릭할 수 있습니다.

기본 아바타 매개변수 이름 접두사는 MCC이고 해당 OSC 패킷 경로 접두사는 /avatar/parameters/MCC입니다. VRC Scaler OSC 응용 프로그램은 해당 매개변수를 OSC 카메라 제어 패킷 경로 /usercamera로 변환합니다. 예를 들어 [5초 후 촬영] 명령, VRC 메뉴의 버튼 매개변수가 MCC/CaptureDelayed이고 사용자가 버튼을 클릭하면 MCC 매개변수 전달 기능을 통해 OSC 패킷 /avatar/parameters/MCC/CaptureDelayed를 수신하고 /usercamera/CaptureDelayed를 VRChat에 반환하여 VRC 카메라가 5초 후 촬영 명령을 실행하도록 합니다.

현재 지원되는 카메라 매개변수는 다음과 같습니다:

| 매개변수 이름 | 유형 | 설명 |
| :---- | :---- | :---- |
| Mode | i | 카메라 모드<br>0: 끔, 1: 사진, 2: 스트림, 3: 이모지, 4: 다층, 5: 인쇄, 6: 드론<br>카메라가 실수로 꺼지는 것을 방지하기 위해 값이 0인 OSC 패킷은 자동으로 무시됩니다. |
| Close, Capture, CaptureDelayed | T | 이 매개변수는 버튼 성질이며 true 값 패킷만 수락하고 false 값 패킷을 자동으로 반환합니다. 카메라가 켜져 있지 않으면 VRChat.exe는 카메라를 켠 후 촬영 명령 (Capture, CaptureDelayed)을 실행합니다. |
| TriggerTakesPhotos, DollyPathsStayVisible, RollWhileFlying, GreenScreen, Lock, OrientationIsLandscape, Flying, SmoothMovement, AutoLevelRoll, AutoLevelPitch, ShowUIInCamera, LocalPlayer, RemotePlayer, Environment, Streaming, ShowFocus, AudioFromCamera, LookAtMe | T/F | 이 매개변수는 카메라가 켜져 있을 때만 /usercamera를 통해 설정할 수 있으며, 카메라가 꺼져 있을 때 메뉴 값을 변경하면 메뉴 값이 카메라의 실제 값과 일치하지 않을 수 있습니다. 매개변수의 자세한 설명은 [공식 공지](https://docs.vrchat.com/docs/vrchat-202533#osc-camera-endpoints)를 참조하세요. |
| Zoom, Exposure, FocalDistance, Aperture, FlySpeed, TurnSpeed, SmoothingStrength, PhotoRate, Duration | f | Float 유형 매개변수는 서로 다른 범위와 기본값을 가지며, 메뉴 RadialPuppet에서 값을 설정할 수 있도록 /avatar/parameters/MCC의 값 범위는 0~1로 조정되고 기본값은 0.5입니다. 자세한 설명과 기본값은 [공식 공지](https://docs.vrchat.com/docs/vrchat-202533#osc-camera-endpoints)를 참조하세요. 또한 이 매개변수는 카메라가 켜져 있을 때만 /usercamera를 통해 설정할 수 있으므로 메뉴의 값이 카메라의 실제 매개변수 값과 다를 수 있습니다. |
| Hue, Saturation, Lightness | f | 녹색 스크린 색상 설정. /avatar/parameters/MCC의 값 범위는 0~1로 조정되고 기본값은 1입니다. |
| LookAtMeXOffset, LookAtMeYOffset | f | 이 매개변수는 /usercamera 매개변수로 직접 변환되지 않지만 메뉴 TwoAxisPuppet의 매개변수로 사용되며 범위는 -1~1입니다. 값이 0.5보다 크거나 -0.5보다 작으면 /usercamera/LookAtMeXOffset 및 /usercamera/LookAtMeYOffset의 부드러운 조정이 시작됩니다. |
| LookAtMeOffsetPuppetOn | T/F | 이 매개변수는 /usercamera 매개변수에 속하지 않으며 현재 메뉴를 통해 LookAtMeX/YOffset을 조정 중인지 판단하기 위해서만 사용됩니다. |
