# **VRC Scaler OSC マニュアル**

## **一、はじめに**

VRC Scaler OSC は、VRChat でアバター身長を変更するためのツール アプリケーションです。VRChat に OSC パケットを送信することで、プラグイン (ギミック) をインストールせずにアバターを機能させることができ、理論上すべてのアバターの身長を変更できます。

### **1.1 主な機能**

* 許可された範囲内でアバター身長を任意に変更でき、即座の変更またはスムーズな変化を選択できます。身長値の単位はメートル、倍数、増減パーセンテージなど様々な方法で入力でき、フィート・インチ入力は自動的にメートルに変換されます。
* ジェスチャー身長調整機能をサポートします。「ワールドをスケーリング」する古典的なモード、異なるジェスチャー組み合わせの選択または無効化が可能です。
* 中国語、英語、日本語、韓国語インターフェースが利用可能で、Windows 64 ビット版と Linux 64 ビット版があります。
* 特定の名前のアバター パラメータを通じて制御でき、アバター メニュー制御プラグイン開発の可能性があります。

### **1.2 プログラム バージョン**

* プログラムは C# で記述され、自社開発の OSC パケット処理パッケージおよび [VRC OSC Query](https://github.com/vrchat-community/vrc-oscquery-lib) を使用します
* デスクトップ (Windows) 版: 中国語、英語、日本語、韓国語インターフェース、Windows 10 以上の OS に対応
* コマンドライン (Console) 版: 英語インターフェース、Windows および Linux 64 ビット OS に対応
* MIT ライセンスの下でオープンソース化する予定です。システムがサポートしていない場合は、ソースコードから自分でコンパイルまたは変更できます。

### **1.3 クイック スタート ガイド**

PCモード：
1. VRCScalerOSC_Windows.exe を実行します。
2. ウィンドウ下部の現在の身長の後ろに現在のアバター身長の値が表示されていることを確認します。
3. スケーリングするキャラクター身長を選択または入力します。
4. [スケーリング実行] ボタンをクリックします。

![](image/img1.3.1.png)
![](image/img1.3.2.png)

VRモード：
1. VRCScalerOSC_Windows.exe を起動します。 
2. VRChatで［OSC］および［OSC 経由で頭部と手首のトラッキングデータの送信を許可］を有効にします。
3. 両手のコントローラーでグリップボタンを押したまま、Muteボタンを2回押して、グリップジェスチャースケール機能を有効にします。
4. 両手でグリップボタンを押し続けた状態で、手を離すと身長が高くなり、手を近づけると身長が低くなります。

### **1.4 よくある質問**

* 身長を変更できないのはなぜですか？  
  A: まず VRChat で OSC 機能が有効になっているか確認してください。

* アプリケーション画面のアバター身長情報が更新されないのはなぜですか？  
  A: 受信ポートが既に使用されていないか、またはファイアウォール/アンチウイルス ソフトウェアがネットワーク機能をブロックしていないか確認してください。VRChat スタンドアロン版 (Quest、Pico) を使用している場合、VRC Scaler OSC は現在これらのバージョンから OSC パケットを受信できず、送信のみできます。したがって、現在の状態表示、ジェスチャー スケーリング、および VRChat メニューを通じた VRC Scaler OSC 制御機能は正常に機能しません。

* VRC Scaler OSC は他の OSC ツールと競合しますか？  
  A: VRC Scaler OSC は VRC OSC Query とランダム受信ポート機能を使用してポート競合を回避します。VRC OSC Query が正常に動作しない場合は、[VOR](https://github.com/SutekhVRC/VOR) などの OSC パケット配信転送ツールを使用して競合を処理できますが、VRC OSC Query に依存するジェスチャー スケーリング機能は正常に動作しない可能性があります。

* ジェスチャー スケーリング機能が正常に動作しないのはなぜですか？  
  A: まず、画面のアバター身長情報が身長の変更に伴って更新されるか確認してください。正常に更新されるのにジェスチャー スケーリングが機能しない場合は、設定画面で [OSC 経由で頭部と手首のトラッキングデータの送信を許可] が有効になっていないか、VRC OSC Query が正常に動作していない可能性があります。

* VRC Scaler OSC のインストールまたは使用に問題が発生した場合、どのようにサポートを求めればよいですか？  
  A: VRC Scaler OSC がリリースされた Web サイトまたは Discord チャネルで作者のサポートを求めてください。

### **1.5 関連製品**

* Real Size Scale Adjuster (RSSAdj) v2: VRC Scaler OSC に基づくアバター プラグイン。プレイヤーが VRChat のメニューを通じて身長を調整できます。
* Menu Control Camera (MCC): OSC を使用して VRC カメラ コマンドを送信します。プレイヤーがメニュー オプションを通じてカメラ設定を調整し、写真を撮ることができます。アバター サイズが大きすぎてカメラを制御するのが難しい問題を解決します。Lite バージョンは既に RSSAdj v2 に統合されています。

### **2.1 ウィンドウ設定**

インターフェース言語はコンピューターのオペレーティング システム言語に自動的に従います。システムが中国語、日本語、韓国語でない場合は、英語版がデフォルトになります。手動で切り替える必要がある場合は、[Lang.] ボタンをクリックして言語を選択してください。

![](image/img2.1.1.png)

デスクトップの解像度が高く、表示スケーリングが 100% の場合、ウィンドウが小さく見えることがあります。[サイズ] ボタンをクリックしてサイズを変更できます。最大 4 倍 (長さと幅は 2 倍) まで拡大できます。

![](image/img2.1.2.png)

[ライト] をクリックすると、元のウィンドウが固定身長値の制御パネルに置き換わり、ユーザーはさまざまな身長値のボタンを通じてより直接的に身長を変更できます。詳細については、セクション 2.8 を参照してください。

### **2.2 身長調整**

左上の [身長] に身長を直接入力し、[スケール変更] を押して身長を変更します。[▼] をクリックするとデフォルト身長メニューが開き、身長をすばやく選択できます。[倍] を使用してスケーリングする場合は、[m] をクリックして倍率に切り替えることができます。[身長リセット] をクリックすると、すぐにアバターのアップロード時のデフォルト身長に復元されます。

![](image/img2.2.1.png)

[身長] の単位は [m] または [倍] で選択できます。[倍] を選択すると、入力値はアバターのデフォルト身長の倍数を表します。現在の身長に基づいて計算したい場合は、パーセンテージ数を入力して末尾に % 記号を追加し、[Enter] キーを押します。入力値は現在の身長のパーセンテージに基づいて自動的に変換されます。入力値が + または - 記号で始まる場合、変換結果は現在の身長に加算されます。

[身長] フィールドは、英国標準単位に慣れたユーザーが寸法を入力しやすくするための自動フィート・インチ変換機能も備えています。入力値に " または ' 記号を含む文字列 (例: 5'3") が含まれている場合、英国標準単位入力と見なされ、入力値は対応するメートル値に自動的に変換され、単位も自動的に [m] に切り替わります。

### **2.3 スケーリング範囲**

スケーリング範囲は、VRC Scaler OSC による身長変更の最大値と最小値を制限するために使用されます。この機能は、VRChat の組み込みキャラクター スケーリング、ワールド スケーリング、またはその他の身長調整ツールのスケーリング効果に影響しません。キャラクター身長ブロックの右上隅のギア アイコンをクリックして、スケーリング範囲設定メニューを開きます。次のオプションがあります:

* Avatarデフォルト (0.2 ~ 5m): VRChat の組み込みスケーリング範囲と同じ
* Worldデフォルト (0.1 ~ 100m): VRChat のワールドで過去に許可された身長範囲
* セーフデフォルト (0.05 ~ 3000m): VR プレイヤーが手持ち円形メニューを見ることができる推奨範囲
* VRChat制限値 (0.01 ~ 10000m): VRChat で現在許可されている身長変更の最大範囲
* カスタム設定ファイル: ユーザー プロファイルに設定された値。特に設定されていない場合は最大範囲
* 上限を選択値に設定: 入力したキャラクター身長を上限として設定します。値は 1 メートル以上である必要があります
* 下限を選択値に設定: 入力したキャラクター身長を下限として設定します。値は 1 メートル以下である必要があります

![](image/img2.3.1.png)

### **2.4 スケーリング速度と時間**

スケーリング速度または時間を変更することで、異なるスムーズなスケーリング効果が得られます。[等速拡縮] がチェックされている場合、毎秒変更される倍数は一定であり、必要なスケーリング時間はターゲット身長と現在の身長の差に応じて増加します。[等速拡縮] をオフにすると、固定スケーリング時間モードに切り替わり、スケーリング速度はターゲット身長と現在の身長の差に応じて増加します。

スムーズなスケーリング効果が不要な場合、[スケール変更] を押すとすぐに身長が変わるようにするには、スケーリング速度を 10000 に設定するか、スケーリング時間を 0 に設定します。

![](image/img2.4.1.png)
![](image/img2.4.2.png)

[自動中断] がチェックされると、スムーズなスケーリング中に現在の身長が予想範囲内にあるかどうかが検出されます。VRChat の組み込み身長調整機能、ワールド身長変更、またはその他のアバター身長ツールの使用により、現在の身長が予想範囲を超える場合、スムーズなスケーリングが自動的に中断されます。VRC Scaler OSC アプリケーションが VRChat から OSC パケットを受信しない場合、現在の身長を検出できず、[自動中断] 機能が正常に動作しない可能性があります。この場合は、[自動中断] をオフにしてこの機能を無効にすることをお勧めします。

### **2.5 ジェスチャー スケーリング**

この機能は VR モードでは両手のコントローラー ボタン組み合わせを使用し、両手のコントローラーが互いに近づいたり遠ざかったりする動作と組み合わせて、アバター身長を直接調整します。デフォルトのジェスチャー スケーリング モードでは、両手が近づくと徐々に縮小され、両手が離れると徐々に拡大されます。[ワールドスケール] がチェックされている場合、両手でワールドのサイズを制御するのと同じようになり、自分は相対的に大きくまたは小さくなります。

[ワールドスケール] では、両手を近づけるとワールドが縮小して自分が大きくなり、両手を離すとワールドが拡大して自分が小さくなります。コントローラー ボタン組み合わせは 5 種類あります。L は左手コントローラーを、R は右手コントローラーを、T はトリガー ボタンを、G はグリップ ボタンを表します。たとえば [LT+RG] は、左手トリガーと右手グリップを同時に押してジェスチャー スケーリングをトリガーする必要があることを意味します。

![](image/img2.5.1.png)
![](image/img2.5.2.png)

[Muteダブルタップでジェスチャー設定] がチェックされている場合は、最初に両手のコントローラーのスケーリング ボタンを押してからミュート ボタンをダブルクリックして、ジェスチャー スケーリングが使用するボタン組み合わせを切り替えることができます。ジェスチャー スケーリングを無効にするには、ボタンを押さずにミュート ボタンをダブルクリックしてジェスチャー スケーリングを無効にします。

![](image/img2.5.3.png)

マイクが [切り替え] モードでない場合、この機能は正常に動作しません。その場合は [イヤーマフモード] の切り替えを代わりに使用できます。[イヤーマフモード] を使用して切り替える場合は約0.5秒の遅延が発生するため、トリガーで [イヤーマフモード] を切り替えた後、変更したいジェスチャーのボタンを押してください。

![](image/img2.5.4.png)

ジェスチャー スケーリング機能は VRC アバター パラメータの GestureLeft および GestureRight パラメータに依存してコントローラー ボタン状態を推測するため、実際のコントローラー ボタン状態とは若干異なる場合があります。以下の表を参照してください:

| :---- | :---- | :---- | :---- |
| Neutral | 0 | ❌ | ❌ |
| Fist | 1 | ✅ | ✅ |
| HandOpen | 2 | ❌ | ❌ |
| FingerPoint | 3 | ❌ | ✅ |
| Victory | 4 | ❌ | ❌ |

### **2.6 OSC 設定**

VRC Scaler OSC アプリケーションは VRC OSCQuery を使用して、自動ポート構成機能を実現し、他の OSC アプリケーションとの競合を回避します。[受信port自動設定] をオフにすると、アプリケーションは指定されたポート上で VRChat に通知して OSC パケットを送信します。VRChat.exe が別のコンピューターまたは VR ヘッドセットで実行されている場合は、[送信先IP] にそのデバイスの IP を入力してください。VRChat が OSC パケットを受信するポートを変更した場合は、[送信port] で調整してください。設定を変更した後、[適用] をクリックして変更を有効にする必要があります。[停止] をクリックするとすぐに、アプリケーションの OSC パケット送受信機能が停止します。

### **2.8 コンパクト モード**

これは簡略版の制御画面で、画面の 25 個のサイズ ボタンをクリックするだけでアバターの身長を変更できます。デフォルトのスムーズなスケーリング速度は毎秒 2 倍です。[即時ズーム] をチェックするとスムーズなスケーリングが無効になります。ボタン上の値の単位のデフォルトはメートルです。[m → 倍] をチェックするとユニットをメートルからアバターのデフォルト身長に基づく倍数に変換できます。末尾が % のボタンの機能は、現在の身長に基づいて固定パーセンテージを増加または減少させることです。[停止] をクリックするとすぐにスムーズなスケーリングが中止されます。[リセット] をクリックすると、アバターのアップロード時のデフォルト身長に直接変更されます。[戻る] をクリックすると、通常バージョンの制御画面に戻ります。

![](image/img2.8.1.png)

### **2.9 コマンドライン (Console) バージョン**

コマンドライン バージョンはデスクトップ バージョンのほとんどの機能を含みます。主な違いはキーボード操作が必要で、英語版のみであり、Linux 64 ビット OS のコンパイル版が利用可能です。ヘルプ ページを切り替えるのに [z] キーを使用する場合を除き、その他のコマンドは入力後に [Enter] キーを押して実行する必要があります。[↑][↓] キーを使用してコマンド履歴を参照することもできます。

**リアルタイム表示情報**:

* **Current height:** VRChat から OSC パケット経由で取得した現在のアバター身長
* **Default height:** アバターアップロード時のデフォルト身長
* **Scale:** 現在の身長のデフォルト身長に対する倍数
* **Range:** 現在のスケーリング上下限
* **Scaling time:** スムーズなスケーリング時間 (秒単位)
* **Scaling rate:** スムーズなスケーリング速度 (倍/秒単位)
* **FixedRate:** 固定速度スケーリング設定ステータス
* **Auto-Abort:** 自動中止設定ステータス
* **Gesture:** ジェスチャー スケーリング設定ステータス

**一般モード スケーリング コマンド**:

* **exit:** アプリケーションを閉じる
* **c:** スケーリングを停止する
* **d:** デフォルト身長に戻す
* **h[数値][単位]:** 指定した [数値] の身長にすぐにスケーリングします。[単位] には [m]、[x]、[p] を入力でき、それぞれメートル、倍数、現在のアバター身長を増減するパーセンテージを表します。
* **s[数値][単位]:** 指定した [数値] の身長にスムーズにスケーリングします。[単位] の説明は上記と同じです
* **g[数値]:** ジェスチャー スケーリング制御。[数値] には 0 ～ 5 を入力でき、それぞれ: 0: ジェスチャー スケーリングを無効にする、1: LT+RT、2: LG+RG、3: LT+RG、4: LG+RT、5: LT+RT+LG+RG
* **ws:** [ワールド スケーリング モード] をオン/オフに切り替える
* **dm:** [ミュート ボタンをダブルクリックしてスケーリング ジェスチャーを切り替え] をオン/オフに切り替える

![](image/img2.9.1.png)

**コンパクト モード スケーリング コマンド**:

* **q[数値]:** 指定した数値で表される身長の値に直ちにスケーリングします
* **w[数値]:** 指定した数値で表される身長の値にスムーズにスケーリングします

  指定した数値と身長は、画面に表示される値を参照してください。下の例では、数値 11 は 15 メートルを表します。

![](image/img2.9.2.png)

**システム構成コマンド**:

* **ip[IPv4 アドレス]:** OSC に使用される IP を構成します
* **port s [数値]:** OSC 送信パケット ポートを構成します。デフォルトは 9000 です
* **port r [数値]:** OSC 受信パケット ポートを構成します。デフォルトは 9010 ～ 9100 のランダム値です
* **t[数値]:** スケーリング時間を秒単位で構成し、固定速度スケーリングを無効にします
* **r[数値]:** スケーリング速度を倍/秒単位で構成し、固定速度スケーリングを有効にします
* **f:** [固定速度スケーリング] をオン/オフに切り替える
* **a:** [自動中止] をオン/オフに切り替える
* **m[数値]:** スケーリング身長の最大値を構成します
* **n[数値]:** スケーリング身長の最小値を構成します

## **3.2 サイズ メニュー同期機能**

VRC Scaler OSC の特徴の 1 つは、ユーザーがコンパクト モードのスケーリング メニュー値をカスタマイズできることです。前のセクションで述べた /DefaultValue{n} シリーズ パラメータは、この機能をアバター プラグインのサイズ リストと同期する実装方法です。メニュー同期機能に加えて、ユーザーは VRChat のメニューを通じて身長値を保存して、後で必要に応じてその値にスケーリングできます。

現在の位置割り当ては以下の通りです:

| 位置番号 | デフォルト値 | 用途 |
| :---- | :---- | :---- |
| 0 | 0 | 一時的な身長機能用に予約<br>デフォルト値 0 はアバター デフォルト身長にスケーリング |
| 1 ～ 25 | 0.01 ～ 10000 | デフォルト身長メニュー (メートルまたは倍数) |
| 26 ～ 33 | -0.5 ～ 0.5 | デフォルト身長メニュー (現在の身長のパーセンテージ) |
| 34 ～ 100 | 0 | ユーザー定義 |

VRC Expressions Menu にサイズ メニューを追加するには、[RadialPuppet] を使用し、[Rotation] パラメータを /DefaultValue{n}/Value に設定して、値がメニューの上に表示されるようにします。次に、メニューの機能ニーズに応じて [Parameter] パラメータを構成します。例えば、[Parameter] を /DefaultValue{n}/Scaling に設定すると、この [RadialPuppet] を開くと /DefaultValue{n}/Value の値を使用してすぐにスケーリングされ、メニューは OSC が false パケットを返すと直ちに閉じます。

![](image/img3.2.1.png)

各サイズ メニュー オプションに一時的な身長値機能を追加するには、[Toggle] または [Button] を使用して対応する機能オプションを作成します。[Button] を使用して、[保存] と [削除] の 2 つのボタンを別々に作成できます。[保存] ボタンの [Parameter] を /DefaultValue{n}/Copy に設定します。ボタンをクリックすると、現在の身長が対応する /DefaultValue{n}/Value に保存されます。[削除] ボタンの [Parameter] を /DefaultValue{n}/Delete に設定します。ボタンをクリックすると、保存した値がデフォルトに復元されます。

[Toggle] を使用して [Parameter] パラメータを /SetValue に設定すると、保存/削除一時値のオン/オフ スイッチを作成できます。

![](image/img3.2.2.png)

特定の身長値をサイズ メニューに直接保存するには、/DefaultValue{n}/InputValue に 0 より大きい値を設定します。値を -1 に設定するとユーザー一時値が削除されます。VRC Scaler OSC アプリケーションが設定値を受信すると、このパラメータが自動的に 0 に設定されます。このパラメータが 0 になったかどうかをチェックして、設定コマンドが完了したかどうかを判断できます。

### **3.3 MCC パラメータ転送機能**

Menu Control Camera (MCC) は、VRC Expressions Menu を通じて VRC カメラを制御できるアバター プラグインです。その制御原理は、アバター パラメータを OSC アプリケーションに送信し、VRChat に usercamera パケットを返送することで、VRC メニューもカメラ制御機能を備えるようになり、アバター身長が高すぎてカメラ パネルのオプションをクリックするのが難しい問題を回避します。デスクトップ モードにはこの問題がなく、マウスでカメラ パネルのオプションを直接クリックできます。

デフォルトのアバター パラメータ名のプレフィックスは MCC で、対応する OSC パケット パス プレフィックスは /avatar/parameters/MCC です。VRC Scaler OSC アプリケーションは対応するパラメータを OSC カメラ制御パケット パス /usercamera に変換します。例として [遅延撮影] コマンド、VRC メニューの button パラメータが MCC/CaptureDelayed で、ユーザーがボタンをクリックすると、MCC パラメータ転送機能を通じて OSC パケット /avatar/parameters/MCC/CaptureDelayed を受信し、/usercamera/CaptureDelayed を VRChat に返送して、VRC カメラに遅延撮影コマンドを実行させます。

現在サポートされているカメラ パラメータは以下の通りです:

| パラメータ名 | 型 | 説明 |
| :---- | :---- | :---- |
| Mode | i | カメラ モード<br>0: オフ、1: 写真、2: ストリーム、3: 絵文字、4: マルチレイヤー、5: プリント、6: ドローン<br>カメラが誤ってオフにされるのを防ぐため、値が 0 の OSC パケットは自動的に無視されます。 |
| Close、Capture、CaptureDelayed | T | これらのパラメータはボタン性質で、true 値パケットのみを受け入れ、false 値パケットを自動的に返送します。カメラが開いていない場合、VRChat.exe はカメラを開いた後に撮影コマンド (Capture、CaptureDelayed) を実行します。 |
| TriggerTakesPhotos、DollyPathsStayVisible、RollWhileFlying、GreenScreen、Lock、OrientationIsLandscape、Flying、SmoothMovement、AutoLevelRoll、AutoLevelPitch、ShowUIInCamera、LocalPlayer、RemotePlayer、Environment、Streaming、ShowFocus、AudioFromCamera、LookAtMe | T/F | これらのパラメータはカメラが開いているときのみ /usercamera を通じて設定でき、カメラが開いていないときにメニュー値を変更するとメニュー値がカメラの実際の値と一致しなくなる可能性があります。パラメータの詳細説明については、[公式アナウンス](https://docs.vrchat.com/docs/vrchat-202533#osc-camera-endpoints) を参照してください。 |
| Zoom、Exposure、FocalDistance、Aperture、FlySpeed、TurnSpeed、SmoothingStrength、PhotoRate、Duration | f | Float 型パラメータは異なる範囲とデフォルト値を持ち、メニュー RadialPuppet で値を設定できるようにするために、/avatar/parameters/MCC の値の範囲は 0 ～ 1 に調整され、デフォルト値は 0.5 です。詳細説明とデフォルト値については、[公式アナウンス](https://docs.vrchat.com/docs/vrchat-202533#osc-camera-endpoints) を参照してください。さらに、これらのパラメータはカメラが開いているときのみ /usercamera を通じて設定できるため、メニュー内の値はカメラの実際のパラメータ値と異なる可能性があります。 |
| Hue、Saturation、Lightness | f | グリーン スクリーン色設定。/avatar/parameters/MCC の値の範囲は 0 ～ 1 に調整され、デフォルト値は 1 です。 |
| LookAtMeXOffset、LookAtMeYOffset | f | これらのパラメータは /usercamera パラメータに直接変換されませんが、メニュー TwoAxisPuppet のパラメータとして使用され、範囲は -1 ～ 1 です。値が 0.5 より大きいまたは -0.5 より小さい場合、/usercamera/LookAtMeXOffset と /usercamera/LookAtMeYOffset のスムーズな調整が開始されます。 |
| LookAtMeOffsetPuppetOn | T/F | このパラメータは /usercamera パラメータに属しておらず、現在メニューを通じて LookAtMeX/YOffset を調整しているかどうかを判断するためにのみ使用されます。 |
